Architecture
~0:40. Step 1: Vercel routes pages to Next.js. Step 2: /api goes to FastAPI, which reads the bundled snapshot. No database and no download at request time, so responses are pure functions of date and cutoff: deterministic and easy to cache. Step 3: locally, Docker Compose mirrors it.

A reproducible snapshot, not a live dependency.

~0:35. Why a snapshot: the client and reviewers get identical numbers, CI is hermetic, and an Elexon outage can't break a demo. Boundary days are included so 1 Jan delivery and 31 Jan decisions both work. Trade-off: not live, which is the obvious phase 2 item. Actuals are an October snapshot, not an as-of archive; documented.

The core rule: one release, the latest at or before the cutoff.

analysis.py
def latest_publication(publications, decision_at):
    """The single most recent publication
    at or before the cutoff, if any."""
    times = sorted(publications)
    index = bisect_right(times, decision_at)
    return times[index - 1] if index else None

# cutoff = delivery day − 1, Europe/London
# hours the run lacks stay as gaps

As the cutoff sweeps the day, the chosen run only changes when a new release lands. Mixing runs would create a forecast nobody ever saw, so we never do.

Cutoffs of 00:00–02:00 use the previous evening's 22:30 run, which covers only 22 hours; those show as gaps, not invented data.

Hourly forecasts, half-hourly actuals. Nothing interpolated, nothing zero-filled.

Alignment & metrics

Each hourly forecast is compared separately with both half-hours it covers, so variation inside the hour counts as error.

Error = forecast − actual (+ means too high)

MAE = mean |error| · RMSE pooled before the root

Accuracy = 100% − WAPE = 100% − Σ|e| ÷ Σ actual

Missing values stay null; scores report matched ÷ expected half-hours. Month scores pool all 1,488 half-hours rather than averaging daily figures.

~0:35. WAPE over MAPE: it weights by volume and doesn't blow up on low-output intervals. Too-high and too-low counts are shown separately because an average signed error can cancel out. docs/methodology.md carries the primary sources and the open questions, such as whether WINDFOR values are interval means.

Small, layered, easy to hand over.
